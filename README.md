# Regiment of Imperial Mongrels — Website Shell

Static, GitHub Pages-friendly starter site.

- Home
- About
- Operations
- Trader's Outpost
- Ship Catalogue
- Projects & Events
- Carriers
- Gallery
- Recruitment

## Design
- Black / charcoal base
- Cyan-blue accent (`#22d3ee`)
- Responsive navigation
- Original squadron logo in `assets/images/branding/`

## Data placeholders
The `data/` directory is ready for future JSON-driven content such as systems, orders, trades, ships, carriers, projects, and members.
