Mongrel Scout Setup

Scout Uplink

Scout is a lightweight EDMC plugin for approved Mongrel members. It watches normal Elite journal events and uploads only the BGS fields needed by Wolf BGS Control when the Regiment of Imperial Mongrels is present.

1. Install EDMCUse a working Elite Dangerous Market Connector installation on the machine that can read your live Elite journal folder.
2. Read the READMEDownload and unzip Scout, then read the top-level README.md before installing. The plugin folder itself can be treated as a black box.
3. Reveal the plugin folderIn EDMC open File → Settings → Plugins → Open. Use the folder EDMC opens rather than looking under Program Files.
4. Copy the MongrelScout FOLDERCopy the whole extracted MongrelScout folder into the plugin folder EDMC revealed; do not copy individual files. Restart EDMC, then enter your Scout token.
5. Test a Mongrel systemEnter or jump within a system where the Mongrels are present. A successful upload shows Updated <system> in EDMC.
6. Leave it runningScout only reacts to FSDJump, Location, and CarrierJump journal events with a full local faction board. Ordinary travel outside Mongrel systems is ignored.

Armed
Scout is enabled and has a token. It is waiting for a qualifying journal event.
Updated <system>
The current BGS snapshot was accepted by the Mongrels server.
Already newer
The server already has a newer observation for that system. Nothing is wrong.
Not assigned: <system>
Your Scout token is restricted and that system is not assigned to it. Contact squad leadership if you should be covering that system.
Token rejected
The token is invalid or no longer active. Ask squad leadership for help.
Scout rate limit reached
Scout has hit its upload safety limit. Leave it running and try again later.
Upload failed
EDMC could not reach the Scout service. Check the network connection first.

Privacy: Scout does not upload your Commander name, cargo, credits, ship build, materials, missions, or general travel history. For a VM or second-PC setup, the important requirement is reliable live access to the Elite journal folder; a direct LAN share is preferable to cloud-sync folders.

Tokens are managed by leadership. Members can use the token they are issued, but token creation, system assignments, access scope, and revocation stay in Wolf BGS Control.
